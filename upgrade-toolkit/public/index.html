2. Run directory:

pending Backup — custom + plain SQL dump, uploads/products backup
pending Verify Backup — the hard gate: restores into a scratch DB and reconciles row counts
pending Offsite Copy — checksum-verified copy to an external drive or network path
pending Upgrade — refuses unless Verify Backup passed. Installs the new version, then runs migrations.
pending Post-Verify — confirms migrations, row counts, and uploads all reconcile
pending Rollback — always available. Restores DB + uploads from this run's verified backup.
